# Security Policy

RAJDOOT is an internal production bot for the India WarEra Discord server.

## Reporting a vulnerability

Please do not disclose credentials, tokens, MongoDB connection strings, Discord IDs that are not already public, or exploit details in a public issue.

Use GitHub's private security advisory mechanism for this repository when available. If that is unavailable, contact the repository maintainers privately through the India WarEra administration team.

## Supported versions

Only the current `main` deployment is supported. Security fixes should be applied to the current production branch rather than maintained as long-lived forks.
