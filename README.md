# India Embassy Bot

Embassy management and access system for the India WarEra Discord server.

## Current implementation slice

- MongoDB durable state and indexes
- Request state machine and audit logging
- Multi-embassy assignment persistence
- OTP generation/hashing/cooldown policy
- WarEra API adapter contract
- Embassy request panel
- Private request-thread creation in the verification channel
- WarEra profile link/ID capture
- `/embassy-setup` admin setup command

See the project Master AI Coding Handoff for the complete business specification.
